# MMSA Review Paper

This repository contains a review paper on **Multimodal Sentiment Analysis (MMSA)**.

## About

This comprehensive review paper explores the field of Multimodal Sentiment Analysis, covering various approaches, methodologies, and techniques used in analyzing sentiment across multiple modalities such as text, audio, and video.

## Contents

The review paper provides an in-depth analysis of current research and developments in the MMSA domain.
